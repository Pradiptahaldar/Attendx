# 🎓 AttendX

> Offline Smart Attendance Management System

## 📖 Overview

AttendX is a modern attendance management system built with Flask.
It is designed for schools, colleges, coaching centers, and offices.

## ✨ Features

- 👨‍🎓 Student Management
- 📷 Face Recognition Attendance
- 📊 Attendance Analytics
- 📁 Excel & PDF Reports
- 🔒 Secure Login
- 📱 Mobile Responsive Design

## 🛠 Tech Stack

- Python
- Flask
- SQLite
- HTML5
- CSS3
- Bootstrap 5
- JavaScript
- OpenCV *(Coming Soon)*
